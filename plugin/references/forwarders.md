# 일본 배송대행 조사 카드

작성 2026-10-05. 출발점 URL이며 최신 요금이나 한국행 전 품목 지원을 보증하지 않는다. 조회할 때 최종 공개 URL·확인시각·근거를 남긴다.

| 업체 | 공식 출발점 | 확인 항목 |
| --- | --- | --- |
| malltail | https://post.malltail.com/services/guide | 일본센터, 항공/해상, 실중량/부피, 기본운임, 유류/처리/검수 옵션, 입고 후 확정 비용 |
| tenso | https://www.tenso.com/jp/estimate | 한국행 방법, 중량 단계, 취급료, 필수 옵션, 인증 준비와 발송 가능 조건 |
| tensojapan | https://www.tensojapan.com/ja/guide/about | 계산기·한국행 제공 여부·수수료·지원 품목·보상·가입 조건 |

각 업체에서 같은 상품/수량·포장·목적지를 입력한다. 불명확하면 추가 조사하거나 미확인 처리한다. third provider 실패 시 다른 정식 배대지를 조사하되 원래 실패를 보존한다. tenso와 転送JAPAN은 다른 업체로 다룬다. EMS/DHL은 업체가 아니라 운송수단이다.

새 견적에 2026-09-21 FJORD 금액/환율을 복사하지 않는다. 카드 할인·신규 회원 혜택은 사용자 적용 여부와 기간을 별도 표시한다. 배대지의 묶음배송과 여러 고객 물량 집약은 서로 다른 개념이다.
