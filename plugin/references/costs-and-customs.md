# 비용과 관세 조사 절차

작성 2026-10-05. 특정 세율·면세 한도·HS 코드는 고정하지 않는다. 정책 근거는 관세청 https://www.customs.go.kr/ 및 UNI-PASS https://unipass.customs.go.kr/ 의 관련 공식 안내로 이동하여 실제 확인한 상세 URL과 날짜를 기록한다. 홈페이지 링크만으로 품목 세율을 확인했다고 하지 않는다.

1. 물건 종류·용도·재질·원산지(발송국과 구별)·수량·가격을 확인한다. 일반 상품이며 서류로 분류하지 않는다.
2. 수입 가능 조건·신고 방식·세금 적용 조건을 조사한다. 분류가 모호하면 사용자 확인/전문 확인 대상으로 표시한다.
3. 세금은 필요한 과세가격·환율·관세율·부가세 등 적용 근거가 확보될 때 계산한다. 현재 helper는 세율을 판단하지 않으며 조사된 예상 세액을 비용 항목으로 받는다. 근거 부족은 tax=null이다.
4. 총비용 구성은 goods + domestic_shipping + handling + international_shipping + mandatory_options + tax. 기타 필수 비용은 mandatory_options에 합산하되 근거 세부표를 함께 보관한다. 이중 계상 금지. 비용이 다른 항목에 포함됐다면 근거를 남기고 추가 청구분 0으로 표시한다.
5. 모든 행의 상품/수량·목적지·포장 조건을 맞춘다. 세금 포함 여부나 할인 조건이 다르면 설명한다. 비용 자체는 quoted/estimated/confirmed_zero로 구분한다. unknown=null, 무상 근거=0.
6. JPY 기준 비교. KRW를 나눌 환율은 `100엔=X원`의 출처·관측시각·기준일·종류가 필요하다. 주말이면 최근 영업일임을 표시한다. 정책상 세금 산정 환율과 비교환율, 카드 청구환율은 따로 관리한다.

가격/재고는 주문 직전 재조회한다. quote expires_at은 관측한 효력 기간 또는 명시한 짧은 연구 캐시 기한이며 업체가 보장한 견적 유효기간과 혼동하지 않는다. 조회 당일이라는 이유만으로 내용이 최신이라고 단정하지 않는다.
