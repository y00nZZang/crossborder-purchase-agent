# 배송대행 견적 비교

[업체 조사 카드](../../references/forwarders.md)와 [관세·비용 규칙](../../references/costs-and-customs.md)을 읽는다. 먼저 상품·수량·목적국·동일 포장 가정 또는 실측을 고정한다. 비교할 배송방법·추적·보상·회원 할인 조건을 표시한다.

공식 계산기/요금표를 현재 브라우저나 검색 도구로 확인한다. 로그인/접근 차단은 미확인으로 기록한다. 지원하지 않는 경로를 숫자로 채우지 않는다. 적어도 3개 서로 다른 업체를 조사하고, 실제 비교 가능한 견적이 3개인지 별도로 보고한다. 동일 업체의 EMS/DHL을 두 업체로 세지 않는다.

[런타임 계약](../../references/runtime.md)의 quote JSON에 원본 통화·구성 비용·출처·관측시각·만료시각을 작성한다. `python3 ../../scripts/purchase_agent.py quote <private-json>`을 실행한다. 경로는 이 SKILL.md를 기준으로 실제 절대 경로를 구한다. 필수 비용이 없으면 null, 무료 근거가 있으면 0이다. unavailable 행의 알려진 소계가 저렴해도 추천 순위에 넣지 않는다.

패키지의 오래된 요율을 실행하지 않는다. JPY 공통 비교, KRW는 출처 있는 `100 JPY = X KRW`를 사용한다. 페이지에 없는 세금·카드 청구액을 확정하지 않는다. 계산 결과는 가장 낮은 **비교 가능한 예상액**이며 운송속도·보상·계정 준비·비용 누락까지 포함한 최적 추천과는 다르다.

출력: 업체/운송방법/원본 금액/JPY 총액 또는 알려진 소계/가정/포함·미확정/관측시각/출처와 추천 이유. 사용자가 몰테일 실험을 선택했으면 다른 최저가가 나와도 경로를 무단 변경하지 않는다.
